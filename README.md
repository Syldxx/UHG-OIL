# Тос, тосолгооны материалын хяналтын систем

Ухаа Худаг уурхайн тос, тосолгооны материалын нийлүүлэлт, агуулахын үзлэг, хэрэгцээний тооцоог хөтлөх систем.

Гэрээт компанийн тосны инженерүүдэд зориулагдсан.

---

## Хурдан эхлэл

Апп нь `index.html` гэсэн **нэг файл**. Build хийх, npm суулгах шаардлагагүй.

- Хөгжүүлэх: файлыг хөтчөөр нээхэд шууд ажиллана
- Байршуулах: GitHub Pages (Settings → Pages → main / root)
- Ажиллаж буй хаяг: `https://<хэрэглэгч>.github.io/<репозитор>/`

---

## Бүтэц

```
index.html          Бүх апп нэг файлд (HTML + CSS + JS + OEM өгөгдөл)
sql/01_schema.sql   Өгөгдлийн сангийн үндсэн бүтэц
sql/02_history.sql  Үлдэгдэл ба тооцооны түүх
```

`index.html` дотор дараах хэсгүүд байна:

| Хэсэг | Агуулга |
|---|---|
| `<style>` | Бүх загвар. CSS хувьсагчаар өнгийг удирдана |
| `var OEM = [...]` | 26 техникийн загварын OEM тосны норм |
| Supabase хэсэг | Нэвтрэх, синк, офлайн дараалал |
| `scrHome` `scrMove` `scrInsp` `scrCalc` | Дөрвөн үндсэн дэлгэц |
| `scrHist` `scrCfg` | Түүх, тохиргоо |
| `render()` | Навигац |

## Дөрвөн модуль

**Нүүр** — нөөцийн светофор, замд яваа хөдөлгөөн, нээлттэй асуудал

**Хөдөлгөөн** — нийлүүлэлтийн хэлхээний 7 салгаа. Хүлээн авахад үлдэгдэл автоматаар шилжинэ

**Үзлэг** — 13 мөрийн агуулахын шалгалт, зөрчлийн давтамжийн хяналт

**Тооцоолуур** — засварын хуваарь дээр суурилсан тосны хэрэгцээний тооцоо

---

## Нийлүүлэлтийн хэлхээ

```
TOTAL Energies → Худалдан авагч → УБ гааль → УБ төв агуулах → Говь агуулах → UHG
```

Нэг ачаа бүх үе шатыг дараалан дамждаггүй. Тиймээс **салгаа бүр бие даасан бичилт** болно. УБ агуулахаас хэсэгчлэн хуваах, яаралтай үед алгасах, агуулахад удаан хэвтэх тохиолдол бүгд багтана.

Хугацааны хяналт зөвхөн замд яваа үед ажиллана. Агуулахад байгаа бараа хоцорсонд тооцогдохгүй — Говь агуулах нь нөөцлөх зориулалттай.

---

## Тооцооны логик

Засварын хуваарь дээрх `MAINT EVENT 500 HOURS_785C` гэсэн мөрийг уншиж:

1. `785C` → `CAT 785C` загвар
2. OEM хүснэгтээс тухайн загварын бүх сав
3. `500 % интервал === 0` бол тухайн сав солигдоно
4. Савны багтаамжийг нэмнэ

Нэмэлт хийлт, гоожилтыг **коэффициентээр** тооцно (анхны утга 1.2). Үндэслэл: тооцоолсон сарын хэрэгцээ ~112,000 л, бодит зарлага 134,521 л.

Тосны шинжилгээгээр солигддог савнууд (`Change on SOS report`) тооцоололд **ороогүй** — тэдгээрт хугацаат интервал байхгүй.

Ачааны багтаамж: **1 машин = 84 нэгж**. IBC = 3.5 нэгж, торх = 1 нэгж (24 IBC = 84 торх).

## Өгөгдлийн сан

Supabase (PostgreSQL). Хүснэгтүүд:

| Хүснэгт | Агуулга | Түүх |
|---|---|---|
| `items` | Бараа, үлдэгдэл, норм | Одоогийн утга |
| `movements` | Хөдөлгөөн | Бүрэн |
| `inspections` | Үзлэг | Бүрэн |
| `stock_log` | Үлдэгдлийн өөрчлөлт бүр | Бүрэн |
| `forecasts` | Хадгалсан тооцоо | Бүрэн |

Эрхийн хяналт (RLS) идэвхтэй. Нэвтрээгүй хүн юу ч харахгүй.

Шинэ төсөл дээр сэргээхэд: `sql/01_schema.sql` дараа нь `sql/02_history.sql` ажиллуулна.

## Синк хэрхэн ажилладаг вэ

Апп нь Supabase-ийн номын сан ашигладаггүй, шууд HTTP хүсэлт явуулна. Тиймээс гадаад CDN-ээс хамаарахгүй, сүлжээ муутай үед ч ачаалагдана.

- Нэвтрэхэд серверээс бүх өгөгдөл татагдана
- Өөрчлөлт бүр дараалалд ороод шууд илгээгдэнэ
- Сүлжээ тасарвал дараалалд хуримтлагдана, толгой дээр улаан цэг гарна
- Сүлжээ орж ирмэгц автоматаар илгээгдэнэ

Локал хуулбар нь `localStorage` дотор `uhg-app` түлхүүрээр хадгалагдана.

## Тохиргоо солих

Өөр Supabase төсөл рүү шилжих бол `index.html` дотроос дараах хоёр мөрийг олж солино:

```js
var SUPA_URL = "https://xxxxx.supabase.co";
var SUPA_KEY = "sb_publishable_xxxxx";
```

`sb_publishable_` түлхүүр ил байхад аюулгүй. **`sb_secret_` эсвэл `service_role` түлхүүрийг энд хэзээ ч бичихгүй** — тэдгээр нь бүх хамгаалалтыг тойрдог.

## Хязгаарлалт

- Хоёр хүн нэг зэрэг ижил утга засвал сүүлийнх нь дарна
- Өтгөн тосны цаг тутмын норм OEM хүснэгтэд байхгүй тул тооцоололд ороогүй
- УБ төв агуулахын үлдэгдэл ERP-ээс автоматаар ирдэггүй, гараар хөтлөгдөнө
- Тооцоолуур нь засварын хуваарийн файлыг автоматаар уншдаггүй, гараар оруулна

## Мэдэгдэж буй өгөгдлийн алдаа

OEM хүснэгтэд CAT 16M-ийн нэг мөрөнд бүтээгдэхүүний нэр нэмэлтийн тайлбартай нийлж бичигдсэн. `index.html` дотор цэвэрлэгдсэн, гэхдээ эх файлаас дахин импортлох бол дахин цэвэрлэх шаардлагатай.

## Нөөцлөлт

Тохиргоо хэсэгт **Нөөц татах** товч бий. Долоо хоногт нэг удаа JSON файл татаж хадгалахыг зөвлөнө.

Supabase өөрөө өдөр тутмын нөөцлөлт хийдэг ч үнэгүй багц дээр хадгалах хугацаа хязгаартай.
